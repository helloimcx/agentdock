# Scheduled Delivery Admission Ownership

- Affected components: automation action executor, ACP submission admission/dispatcher, scheduled channel gateway, delivery outbox.
- Changed fact: scheduled channel execution marks the admitted inner ACP run id as outbox-owned synchronously after durable admission and before dispatcher drain. The gateway suppresses live final-reply bridge events for owned runs while progress continues to stream; after completion the persisted outbox is the sole final-message delivery path.
- Rationale: previously ownership was registered after completion polling, allowing the live bridge and outbox to deliver the same final answer. Registration now precedes dispatcher execution and closes that duplicate window.
